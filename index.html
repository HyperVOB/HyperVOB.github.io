Archive interactive discs, menus included, into a compact, modern library your media server plays natively.

A plain rip turns each title on a disc into a separate video file and loses the menus, the extras' names and the games. HyperVOB keeps them. It runs the disc's own navigation program against the re-encoded media, so the archive plays as the disc did and you no longer need the disc itself. The library is still a set of ordinary video files your media server already understands.

Discs
DVD today. Blu-ray is planned after 1.0.
Media servers
Jellyfin today, with HyperVOB's plugin. Others may follow.
Library format
Open: a written specification, licensed CC BY 4.0, that any player can implement.

Status

HyperVOB is a working prototype and isn't public yet. Its code and documentation will be published on GitHub when it is.

It is developed primarily with AI assistance (Claude Code), reviewed and directed by its maintainer.
